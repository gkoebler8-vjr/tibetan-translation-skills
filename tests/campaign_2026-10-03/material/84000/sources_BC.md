# Sources and method for Sets B and C (84000 material)

Method is exactly that of `sources.md` (read that first): 84000 GraphQL API (`https://graphql.84000.co/api/graphql`, header `apollo-require-preflight: true`, no authentication); each English passage comes with the Tibetan span 84000 itself aligned to it (`passages.alignments[].tibetan`); English rendered from `passage.json` (verse line breaks, including verse nested in `blockquote` in the commentaries) and checked against `passage.content` (all 70 units: identical apart from whitespace); Tibetan = the raw 84000 alignment string with the physical Derge line breaks joined and, for verse units only, broken after each `། །`; `[F.n.a/b]` folio markers kept in place. Every Tibetan string was checked against the 84000 source-view page(s) `https://read.84000.co/source/tohN/folio/<leaf>` (the leaf before, the leaf itself and the leaf after were concatenated, everything except Tibetan characters stripped, and the whole alignment string required to occur in it). Result: all 70 units match; 6 units match only when split at a folio marker that falls on a leaf boundary (the source view inserts its page header between leaves): they are listed per passage below. No mismatch between alignment text and source view was found. No Esukhia/GitHub text was used. Licence for all six: CC BY-NC-ND 4.0. Nothing was translated or paraphrased; the notes below only describe the alignment.

Files in this folder: `B_sutra.md`, `B_tantra.md`, `B_shastra.md` (Set B, for iteration 2); `C_sutra.md`, `C_tantra.md`, `C_shastra.md` (Set C, final test); `*_raw.json` (unprocessed alignment strings and English per unit, same as before); `*_diag.json` (per-unit kind, English line count, Tibetan line count, source-view check result, folio side); helper scripts `fetchfull.py` (dump a work with passage json), `win.py` / `view.py` (window search and preview), `build2.py` / `run_BC.py` (builder; reuses `fetchwork.py`), `meta_BC.json`, `ack_BC.json` (imprint/acknowledgment data), and `f*.json` (full passage dumps with structure). These can be deleted.

Verse/prose labels follow 84000's own structure (a passage is verse if it contains a line group) with one correction: Toh 431, 15.9 is marked as a line group in the 84000 data but is prose in the Tibetan and English (one sentence per line), so it is labelled prose and its lines are joined with spaces. A verse unit that opens with a speaker introduction ("The Blessed One said:") keeps that introduction inside the unit, as in Set A. Heading metadata in each file gives work uuid, 84000 version, translators, imprint source edition, and the passage context.

## Catalogue findings (why other works on the brief were not used)

From the API catalogue (`works.json`, publicationStatus 1 / 1.a = published; 2.x = translated but not yet published, for which `work(uuid)` returns null, so no aligned passages can be retrieved):
- Not retrievable (status 2.x): Toh 442 Guhyasamāja (2.e), Toh 366 Vajraḍāka/Ḍākinījālaśaṃvara (2.g), Toh 373 Saṃvarodaya (2.g), Toh 494 Mahāvairocanābhisaṃbodhi (2.h). The API returns `work: null` for each (checked).
- Toh 467 in 84000's catalogue is the Tantra of Black Yamāri (published, but much of it is mantra and ritual lists), not Hevajra; the Hevajra Tantra is Toh 417 / 418 (published 2025). Toh 543 (Mañjuśrīmūlakalpa) is published but is Sanskrit-based and mostly mantra and ritual verse; Toh 425, 384, 440 are published but essentially all verse with no prose passages (Toh 425, 384) or ritual (Toh 440).
- Published sutras tried: Toh 113, 100, 147, 160, 176, 231 (all dumped and window-searched); Toh 113 and 147 gave clean prose-verse alternation. Toh 176, 160 and 100 are mostly prose with verse only in short blocks (few windows with both and several transitions); Toh 231 has almost no verse passages (19 of 638).
- Published Tengyur works (status 1/1.a), complete list: Toh 1183, Toh 1189 (both Hevajra commentaries), Toh 3156 (a one-passage dhāraṇī), Toh 3808 (used in Set A), Toh 3990 (2 pages, 12 prose passages, no verse), Toh 4568-3 ("The Third Well-Spoken Branch: An Exact Account of How All the Victorious One’s Teachings E...", a Tibetan-authored work in the Tengyur catalogue, 131 passages of which 35 are verse; not an Indian treatise and not used). So only two usable "other" shastras exist, and Toh 1189 is B and Toh 1183 is C, as the brief anticipated. Because both comment on the Hevajra Tantra, they share vocabulary with the Set B tantra (Toh 417); the passages themselves do not overlap.
- Commentary limitation: in Toh 1189 and Toh 1183 most quoted root-text verses have an empty Tibetan alignment (84000's Tibetan commentary gives only the opening words of the verse, while the English quotes the whole stanza from the Sanskrit/Tantra). Spans were therefore chosen only where every unit has non-empty Tibetan. That is why the Toh 1183 span is early in the chapter (leaves 6-7 of ff. 1.b-61.a; it is not the opening or the colophon, but it is not mid-text either) and Toh 1189's is about a quarter into the text (leaves 251-252 of 221.a-297.a).
- Basis of the 84000 English (matters for comparison with the Tibetan): Toh 113 (from Tibetan with reference to Sanskrit), Toh 147 (from Tibetan), Toh 417 (based on the Tibetan Degé text, 84000 introduction i.9), Toh 431 (from the Sanskrit, then compared with the Tibetan), Toh 1189 and Toh 1183 (from the Sanskrit edition, then compared with the Tibetan). Where the English follows the Sanskrit the English and the Tibetan commentary can differ in wording and in which words introduce a quotation.
